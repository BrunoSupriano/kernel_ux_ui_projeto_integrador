Seções recolhíveis que organizam os conteúdos da disciplina por módulo, semana ou tema (A05, P05).

**O consumidor fornece:** o título da seção (escolhido pelo professor), o contador de itens novos e os itens dentro.

- Use `details`/`summary` nativos: teclado e leitor de tela funcionam sem código extra.
- A seção mais recente abre por padrão; as demais ficam recolhidas. O selo "1 novo" indica novidade sem abrir.
- A seta gira ao abrir, mas o estado também é anunciado pelo navegador.
- Dentro do painel use `ContentItem`.
