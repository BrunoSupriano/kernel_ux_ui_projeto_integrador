Campo de texto de várias linhas para devolutivas, descrições, avisos e comentários.

**O consumidor fornece:** rótulo, dica e, se houver limite, um contador de caracteres perto do campo.

- Altura mínima de 112px; o usuário pode redimensionar na vertical.
- Para enunciados com formatação (P08), coloque uma barra de ferramentas acima, em botões `ava-btn--ghost` com rótulo acessível.
- Salve o rascunho sozinho e mostre `Autosave`.
