Estado vazio que explica por que não há nada e oferece um próximo passo, usado em listas de avisos, busca sem resultado e blocos do dashboard.

**O consumidor fornece:** o título, uma frase de explicação em linguagem simples e, quando houver, uma ação.

- Fale do que o usuário pode fazer ("Ver minhas disciplinas"), não do que o sistema não tem.
- Fundo `surface-raised`, contorno tracejado `border-strong`, ícone dentro de círculo `tint-100`.
- Busca sem resultado: sugira outra grafia ou o nome da disciplina.
- Não use para erro: erro usa `Alert` ou a página de estado (G06).
