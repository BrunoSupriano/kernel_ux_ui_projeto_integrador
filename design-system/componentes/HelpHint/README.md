Ajuda contextual com botão e dica curta, usada em telas complexas como o editor de plano (P04) e as preferências de notificação (G03).

**O consumidor fornece:** o texto do botão ("Como funciona …?") e uma explicação de até duas frases.

- O botão tem **rótulo visível**, não é só um "?". A dica aparece ao focar ou passar o mouse e fica ligada por `aria-describedby`.
- A dica usa `ink` com texto branco (14,8:1), sem sombra. Conteúdo longo vai para a Central de Ajuda, não para a dica.
- Escreva a dica no vocabulário do usuário, sem termos de banco de dados.
