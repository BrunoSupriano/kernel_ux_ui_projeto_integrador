Lista suspensa nativa para escolher uma opção entre quatro ou mais.

**O consumidor fornece:** o rótulo, as `option` e uma opção inicial que oriente ("Escolha um período") quando a escolha for obrigatória.

- Use `Select` a partir de quatro opções. Com duas ou três, use rádios (`ChoiceControls`), que deixam as opções visíveis.
- Mantém o controle nativo para ter teclado, leitor de tela e rolagem corretos.
- Erro segue o mesmo padrão do `TextField`.
