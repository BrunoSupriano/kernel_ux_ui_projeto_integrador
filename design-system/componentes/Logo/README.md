Logo, símbolo e ícones da marca Instituto Kernel, com a versão certa para cada fundo.

**O consumidor fornece:** o fundo onde a marca será colocada, para escolher o arquivo. Os SVGs estão nos grupos de assets Logo, Símbolo e Ícones.

- Fundo claro (`surface`, `surface-raised`): `kernel-logo-claro.svg`. Fundo `primary-deep`: `kernel-logo-escuro.svg`. Fundo `primary`: `kernel-logo-verde.svg`.
- Menu lateral: logo `escuro` a 28px de altura. Login: logo com INSTITUTO, versão `claro`, 160px de largura ou mais.
- Mínimo de 80px de largura (logo simples) e 140px (com INSTITUTO). Área de proteção igual à altura do "k".
- Escreva sempre um texto alternativo no `<img>` ("Instituto Kernel") quando a logo for o único nome da marca na tela; se o nome já aparece em texto ao lado, use `alt=""`.
- Não recolora, não estique e não troque a cor do sublinhado. Não use ícone `k_` em botão ou menu: para interface use os ícones do componente Icons.
