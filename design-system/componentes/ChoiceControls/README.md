Caixas de seleção (várias respostas) e botões de rádio (uma resposta) com rótulo clicável e dica.

**O consumidor fornece:** um `fieldset` com `legend`, cada opção dentro de `label.ava-choice` e, se precisar, uma dica abaixo do rótulo.

- Checkbox quando o usuário pode marcar várias opções; rádio quando só uma vale. Duas ou três opções excludentes: rádio; mais: `Select`.
- O rótulo inteiro é clicável. A área mínima é de 40px de altura.
- O estado marcado combina cor `primary` com marca visível (✓ ou ponto central); nunca só cor.
- Opção desabilitada precisa explicar o motivo na dica.
