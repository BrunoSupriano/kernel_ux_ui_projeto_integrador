# Ícones da marca

[← Marca](../README.md) · [README principal](../../README.md)

Ícone `k_` em tile para app, favicon, avatar e ícone de projeto. Cada combinação tem SVG e PNG em 16, 32, 48, 64, 128, 180, 256, 512 e 1024 px.

- `quadrado` serve para loja de app, `apple-touch-icon` e ícone maskable (o sistema aplica o arredondamento).
- Tamanho mínimo: 16 px.
- **Não confundir com os ícones de interface.** Os 53 ícones de traço usados em menus, botões e status ficam no design system: [`design-system/icones-interface/`](../../design-system/icones-interface/README.md).
