# Marca · Instituto Kernel

[← README principal](../README.md)

O **Instituto Kernel** é a instituição fictícia de ensino superior em engenharia de software criada pela equipe para dar identidade ao AVA. A logo é a palavra `kernel` em minúsculas seguida de um underline, o cursor piscando de um terminal: o próximo passo ainda vai ser escrito. Slogan: **Escreva o futuro.**

## Regras rápidas

- **Área de proteção:** ao redor da logo, pelo menos a altura da letra "k".
- **Tamanho mínimo:** logo simples 80 px de largura; com INSTITUTO 140 px; ícone 16 px.
- **Âmbar `#E3A72F`:** só no underline da versão `verde`. Nunca como texto nem sozinho sobre branco.
- Não estique, não gire, não troque as cores do underline e não coloque a logo sobre foto sem escurecer o fundo.
- Tipografia: **Plus Jakarta Sans** (OFL), pesos 500 e 800.
